SMART TO-DO LIST - FINAL PROJECT
================================

The main project is index.html. It is a standalone file containing HTML, CSS and JavaScript so it works correctly when opened directly on a mobile phone.

Features:
- Add tasks
- Complete/uncomplete tasks
- Delete tasks
- All / Active / Completed filters
- Clear Completed
- LocalStorage saving
- Responsive mobile design

To run:
1. Extract the ZIP file.
2. Open index.html directly in Chrome or another browser.
3. The project will display the Smart To-Do List design.

Submission:
Send the complete ZIP file. The extra style.css and script.js files are included for project organization; the standalone index.html is the file to open.
